# English IT Trainer

Отдельный статический сайт для изучения английского с фокусом на IT и технические инструкции.

## Что внутри

- 20 базовых разговорных фраз из предыдущей версии.
- 29 новых IT-блоков из технических инструкций.
- Отдельный режим `10 главных IT-блоков`.
- Режимы: знакомство, русский → английский, ситуация → английский, на слух.
- Speech Synthesis для английской озвучки.
- Ручная самооценка и сохранение прогресса в `localStorage`.
- Адаптивная мобильная версия.
