Все 29 IT-блоков

У каждого блока есть значение, подсказка для памяти и рабочий пример. Это не список «слово = перевод», а строительные детали языка.

Как заниматься

1. Начни с набора «10 главных IT-блоков». Режим «Русский → английский блок». Не открывай ответ 5–10 секунд.

2. После первого круга переключись на «Ситуация → английская фраза». Здесь задача уже не назвать слово, а достать его в живой конструкции.

3. Потом включи «На слух». Сначала пойми смысл примера без текста, после этого открой ответ.

4. Когда 8–10 из 10 идут самостоятельно, переходи к «Все 29 IT-блоков». Не пытайся выучить все 29 за один заход.

Важная разница: function и functional

function = функция (существительное) или функционировать (глагол). functional = функциональный / работоспособный (прилагательное). Поэтому правильно: when using this function, а не using this functional.
